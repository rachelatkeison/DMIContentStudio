# DMI Content Studio
A full-featured Digital Musical Instrument Content Creation App built in **C++ with JUCE 8**.

## Features
- Piano roll & style pattern editors
- MIDI playback and recording
- Voice/CC control
- SMF import/export
- JSON project save/load

## Built With
- JUCE 8.0.10
- Xcode (macOS)
- macOS IAC MIDI bus for testing
